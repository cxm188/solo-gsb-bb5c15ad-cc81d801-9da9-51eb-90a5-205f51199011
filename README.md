# 视频接片单核对工具

粘贴 CSV 接片单，按实际帧数核对素材与成片时长是否一致，并对成片时间线做全局空隙 / 重叠扫描。

- 前端：React + TypeScript（Vite）
- 后端：Node.js + Express（TypeScript）
- 时间码：`HH:MM:SS:FF`，入点包含、出点不包含
- 帧率模式（整单统一选择）：
  - **25fps 非丢帧**：帧号 00–24
  - **29.97fps 丢帧**：按 30fps 标称计数，帧号 00–29；每分钟跳过 00、01 帧号，整十分钟不跳
- 自动拒绝：非法帧号、越界字段、零长度 / 倒序（跨午夜）区间
- 空隙与重叠为**全局扫描**（排序 + 扫描线，不只比较相邻行），并标注相关原始行号
- 点击问题条目可定位并高亮原始行；时间码与帧数同时显示

## 启动（一条命令）

```bash
docker compose up --build
```

依赖安装已纳入镜像构建（Dockerfile 多阶段构建中执行 `npm install`），无需手动安装。

启动后访问：**http://localhost:3000**

## 配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `PORT` | `3000` | 容器内服务监听端口，在 `docker-compose.yml` 的 `environment` 中修改 |
| 端口映射 | `3000:3000` | 宿主机访问端口，修改 `docker-compose.yml` 的 `ports`（如 `"8080:3000"` 则访问 http://localhost:8080） |

## CSV 格式

每行 5 列，首行可以是表头（自动识别跳过）：

```csv
片段名,素材入点,素材出点,成片入点,成片出点
片头,00:00:01:00,00:00:06:00,00:00:00:00,00:00:05:00
```

- 支持引号包裹字段与 CRLF 换行
- 仓库根目录的 `sample-edl.csv` 为示例接片单（也可在网页中点击「加载示例接片单」），其中故意包含一处空隙、一处时长不匹配和一处重叠，便于验证功能

## 核对规则

1. **时长一致**：每行 `素材出点 - 素材入点` 与 `成片出点 - 成片入点` 的实际帧数必须相等（出点不包含）。
2. **成片空隙**：成片区间按入点排序后，任何未被覆盖的区间都会列出（含前后行号、时间码与帧数）。
3. **成片重叠**：任意两行成片区间相交都会列出（不限于相邻行，含双方行号、重叠区间的时间码与帧数）。

## 本地开发（不用 Docker）

```bash
# 后端（终端 1，http://localhost:3000）
cd server && npm install && npm run dev

# 前端（终端 2，http://localhost:5173，/api 已代理到 3000）
cd web && npm install && npm run dev
```

## 测试

```bash
cd server && npm install && npm test
```

覆盖：25fps 非丢帧解析、29.97fps 丢帧跳号规则（含整十分钟例外）、非法帧号 / 跨午夜拒绝、帧数↔时间码往返换算、时长比对、全局空隙与重叠扫描。

## API

`POST /api/check`

```json
{ "csv": "片段名,素材入点,...", "mode": "ndf25" }
```

`mode` 取值：`ndf25`（25fps 非丢帧）/ `df2997`（29.97fps 丢帧）。返回逐行结果、时长不匹配、空隙与重叠列表。
